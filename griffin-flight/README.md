# Путь грифона

Оригинальная браузерная игра о полёте грифона над лесами и деревнями. Отзывы и оценки сохраняются на сервере в SQLite.

## Запуск

Нужен Node.js версии 22.13 или новее с поддержкой `node:sqlite`.

```powershell
node C:\claude\griffin-flight\server.js
```

Откройте http://127.0.0.1:5500. Держите сервер запущенным во время публикации. База находится в `reviews.sqlite` рядом с `server.js`; не удаляйте её, если нужно сохранить отзывы.

## Pangolin

1. Создайте Site в панели Pangolin и сохраните его Endpoint, ID и секретный ключ в надёжном месте.
2. Скачайте Newt по ссылке из задания и запустите его в отдельном окне, используя Endpoint, ID и секрет из панели. Не публикуйте эти данные.
3. Создайте публичный HTTP-ресурс с требуемым преподавателем поддоменом. Добавьте цель: ваш Site, протокол HTTP, Host `127.0.0.1`, Port `5500`.
4. Отключите платформу SSO в настройках аутентификации ресурса, сохраните и проверьте полученный HTTPS-адрес с другого устройства или в приватном окне.
5. Оставьте запущенными и Node.js, и Newt. Не отправляйте ссылку в группу до проверки.

Взаимные оценки и исправление по обратной связи необходимо выполнить после получения настоящих отзывов.
